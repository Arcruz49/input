## 1. Instalar o .NET 10 SDK
 
[Baixar aqui](https://builds.dotnet.microsoft.com/dotnet/Sdk/10.0.400/dotnet-sdk-10.0.400-win-x64.exe) e instalar.
 
## 2. Baixar o projeto
 
Clone com Git:
 
```
git clone https://github.com/Arcruz49/input.git
```
 
Ou baixe o ZIP em https://github.com/Arcruz49/input (botão **Code → Download ZIP**) e extraia.
 
## 3. Rodar
 
Abra o CMD dentro da pasta do projeto (onde está o `Input.csproj`) e rode:
 
```
dotnet run
```
 
A primeira execução demora um pouco (baixa dependências e compila). Depois o app abre sozinho.
